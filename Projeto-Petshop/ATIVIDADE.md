# Atividade de Melhoria: PetShop Amigo Fiel

## Descrição Geral

Você irá aprimorar o site do PetShop Amigo Fiel, que já possui as seções principais (Home, Serviços, Galeria, Contato, Localização) e um layout inicial com HTML, CSS e JavaScript. O objetivo é propor melhorias e novas funcionalidades, trabalhando em duplas ou trios.

---

## Desafios de Melhorias

### 1. Links para redes sociais e WhatsApp no rodapé

- Adicione ícones e links para as principais redes sociais (Instagram, Facebook, etc.) e um link para contato via WhatsApp no rodapé do site.

### 2. Seção de Produtos

- Crie uma nova seção no site apresentando pelo menos 6 produtos (nome, imagem, preço e breve descrição).

### 3. Página Sobre

- Crie um novo arquivo `sobre.html`.
- Adicione um link para esta página no menu de navegação.
- O conteúdo deve apresentar a empresa "PetShop Amigo Fiel" (Quem somos, missão, valores, história, etc.).

### 4. Alterar Paleta de Cores

- Modifique as cores principais do site, escolhendo uma nova paleta harmônica.
- Atualize as variáveis CSS e garanta contraste e acessibilidade.

### 5. Temas Claro e Escuro

- Implemente a opção de alternar entre tema claro e escuro.
- O usuário deve poder escolher o tema (pode ser um botão ou switch visível no site).

---

## Entregáveis

- Código-fonte atualizado (HTML, CSS, JS e imagens se necessário).
- Novo arquivo `sobre.html`.
- README atualizado com instruções de execução e descrição das melhorias implementadas.

## Critérios de Avaliação

- Funcionalidade e usabilidade das melhorias.
- Organização e clareza do código.
- Criatividade e capricho visual.
- Trabalho em equipe (dupla ou trio).

---

## Dicas

- Utilize sites como [Coolors](https://coolors.co/) para escolher paletas de cores.
- Para ícones, use [Font Awesome](https://fontawesome.com/) ou SVGs gratuitos.
- Lembre-se de testar o site em diferentes dispositivos (responsividade).
